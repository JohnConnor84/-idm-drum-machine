# Sample Banks

Each folder inside `banks/` represents one complete sample bank.

Example:

```text
IDM_DARK/
├── 1.1.wav
├── 1.2.wav
├── 2.1.wav
├── 13.1.wav
├── 13.2.wav
├── 13.3.wav
├── 13.4.wav
└── 16.1.wav
Naming convention
VOICE.SAMPLE.wav

For example, 13.4.wav means voice 13, sample 4.

Voices: 1–16

Samples per voice: 1–32

Audio format: WAV

Not every voice needs to contain the same number of samples.

Important
This directory is reserved for your sample banks. The current prototype does not yet implement bank loading.
